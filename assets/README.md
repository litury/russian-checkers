# Исходники ресурсов

Эта папка не загружается игрой и не копируется в сборку.

- `sources/match-actions` — PNG-исходники кнопок отмены, сдачи и диалогов.
  Готовые WebP-атласы находятся в `client/app/ui/match-actions`.
- `sources/audio` — сведения о происхождении игровых звуков.
  Игровые файлы находятся в `client/app/audio/menu`.
- `sources/font-sources.json` — источники и контрольные суммы шрифтов.

Исторические пути в записях генерации описывают получение ресурсов, а не текущую структуру.
Исходные лицензии шрифтов находятся в `client/fonts`. Отдельные публичные копии удалены;
перед распространением сборки нужно обеспечить соблюдение условий лицензий шрифтов.

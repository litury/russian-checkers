# Панели игроков

Готовые изображения рамки и внутренней поверхности панелей игроков.
`steam-sheet.png` — атлас анимации 6×3 ячеек размером 72×56 пикселей.

Имена, время и статус рисуются текстом Phaser, а не встроены в изображения.
Код сборки панели — `client/features/match/hud/bunkerPanel.ts`, размеры — `client/features/match/hud/playerPanelLayout.ts`.
`opening-mask.png` сохранён как исходная маска и не загружается игрой.

Исходные лицензии шрифтов находятся в `client/fonts/`.
Общее описание ресурсов и исходников — в `docs/assets/README.md`.

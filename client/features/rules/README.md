# Правила русских шашек

Источник: «Правила вида спорта “шашки”», приказ Минспорта России
от 17.03.2022 № 201. Русский оригинал опубликован Федерацией шашек России:
https://shashki.ru/download/2022/doc/FSHR_shashki_pravila_2022.doc

Документ проверен 23 октября 2026 года по текущему разделу документов ФШР
и карточке https://www.consultant.ru/document/cons_doc_LAW_413197/.
Более новая заменяющая редакция в проверенных источниках не обнаружена;
дата проверки не объявляется датой редакции. Ежегодные положения соревнований
и стандарты спортивной подготовки не подменяют правила игры.

Справка в `index.html` — краткое объяснение игры, не полный нормативный текст.
Ссылка на оригинал находится в начале. Номера пунктов и реквизиты приказа
не перегружают экран; сопоставление для проверки текста:

- Расстановка и ход: 6.1.1, 6.1.3.1, 6.1.4.1, 6.1.4.3.
- Взятие: 6.1.5.1, 6.1.5.3, 6.1.5.5–6.1.5.9, 6.1.5.12, 6.1.5.14.
- Дамка и превращение: 6.1.4.4–6.1.4.5, 6.1.5.2, 6.1.5.15–6.1.5.16.
- Завершение партии: 6.1.7, 5.4.2.6, 5.4.2.10, 5.4.13.1.
- Время: 5.4.2.1, 6.1.5.3, 6.1.9.3. Варианты сайта определены в `shared/rules/timeControl.ts`.

Готическая рамка использует существующий атлас. Только центральный участок
nine-slice под текстом заменён непрозрачным спокойным цветом. Стили ограничены
экраном правил и не меняют фон профиля, настроек или меню.

Условия сайта отделены от нормативных положений. При изменении справки сверять
формулировки с оригиналом и не обещать поведение, которого нет в `shared/rules`.

## Соответствие движка

| Основание | Реализация |
| --- | --- |
| 5.4.13.1, повторение позиции | Автоматически, с той же очередью хода; счётчики окончаний не входят в ключ позиции. |
| 5.4.13.3–5.4.13.4, соглашение | Онлайн: после своего хода, принятие/отказ; ответный ход отвергает предложение. После отказа тот же игрок ждёт предложения соперника. |
| 6.1.8.3–6.1.8.4 | 15 ходов сильнейшей стороны с момента установления соотношения. Для трёх дамок против одной проверяется владение большой дорогой. |
| 6.1.8.6 | По 5/30/60 ходов каждой стороны в окончаниях с 2–3/4–5/6–7 шашками при наличии дамок у обеих сторон. Взятие или превращение обнуляет счётчик. |
| 6.1.8.8 | По 15/25 ходов каждой стороны только дамками в окончаниях с 4–5/6–7 шашками. Взятие или ход простой обнуляет счётчик. |
| 5.4.2.10 | Завершённый вовремя ввод выигрышного хода не проигрывает из-за последующей анимации. Сервер проверяет результат позиции до присуждения просрочки. Поздний ввод не принимается. |

Счётчики обновляются один раз на полный ход, хранятся в позиции и передаются
со снимком сервера; воспроизведение и отмена против компьютера сохраняют их.
Счётные ничьи фиксируются автоматически: это политика платформы, а не буквальное
воспроизведение устной заявки и проверки бумажного бланка судьёй.

## Оставшиеся ограничения

- 6.1.8.5: пятиходовое окончание на большой дороге имеет исключение при возможности
  выигрыша любой стороны. Без доказательного анализа позиции или судьи не объявляем
  его ничьей автоматически только по числу шашек.
- 6.1.8.7 и 6.1.10.5: оценка «явно ничейной»/выигранной позиции и обращение к судье
  не реализованы. Материальный перевес не заменяет судейскую оценку.
- Выбираемые режимы сайта всегда с добавлением; специальные положения для игры
  без добавления не заявляются как реализованные. `1+0` оставлен для старой истории.
- Нет турнирной жеребьёвки, судейского кабинета, апелляций, идентификации участников
  официального соревнования и системы контроля внешних подсказок.

Наличие ссылки на официальный документ не означает официального турнирного
статуса или полного соответствия всей процедуре проведения соревнований.

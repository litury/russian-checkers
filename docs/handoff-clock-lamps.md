# Часы: лампы на смене хода (не вечное мигание)

Арт уже в `src/client/app/ui/`. Новый PNG не нужен. Phaser — `@developer`. Коммит/пуш только если человек сказал.

## Ошибка предыдущей спеки

Петля `0→1→2→1→0` на обоих шеллах **неверна**. Человек: лампы **не** мигают всё время.

## Поведение

Ход белых (ты) / чёрных (враг) как сейчас: активный = зелёный `ok`, неактивный = красный `hot`. `turn == null` → оба `idle`, без анимации.

Пока ход твой:
- твои часы **зелёные**, лампы **горят и держат** (кадр 2), не петлят
- враг **красный**, лампы **тусклые** (кадр 0)

Когда сходил (смена `turn`):

**Ушедший с хода** (был зелёный → станет красный):
1. лампы плавно тухнут по кадрам **2→1→0**, на 1–2 кнопки чуть вдавлены
2. шелл становится красным
3. красные лампы **не** зажигаются в полную — остаются тускло (hot кадр 0)

**Кто получил ход** (был красный → станет зелёный):
1. красные лампы/кнопки: нажатие и тускнеют **2→1→0** (если уже кадр 0 — короткий press кадр 1 и обратно, либо сразу к зелёному)
2. шелл зелёный
3. лампы загораются **0→1→2** и **держат** кадр 2

Обе стороны играют **параллельно** на одном `setClock` со сменой хода. Повторный `setClock` с тем же `turn` — не переигрывать. Цифры Tiny5 как есть. Display 112×70. Idle не анимировать.

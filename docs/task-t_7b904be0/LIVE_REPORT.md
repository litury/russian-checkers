# Дополнение после QA request-changes: реальный API и браузер

Кандидат основывается на 26140f7; эта доработка не меняет тексты фаз или логику поиска. Заменяет прежнее ограничение REPORT.md об отсутствии pg/живого API. Авторская проверка, не независимый QA PASS.

## Изменение

Реальные замеры выявили недостаточный запас «В меню» в уже существующем online hub. С фиксированными концами арта по 22px мобильная кнопка 94px давала отрицательный запас. Теперь минимальная ширина 116px на телефоне и 124px на desktop. Добавлен onlineHubGeometry.spec.ts. Сам hub остаётся существующим отдельным диалогом: фаза online-hub не показывает search cassette, что прежний DOM fixture ошибочно не учитывал. Его заголовок слева в широкой рамке, а не в центрированном пазу search-header.

## Реальные фазы

Все 20 измерений используют ровно соответствующий state WebP и одинаковые border-image-slice 40 48 fill, border-image-width 20px 24px. Кадры button-*.png и button-live-measurements.json. Накладки не меняют размер; середина растягивается.

## Воспроизведение независимым QA

В собственной копии кандидата, со свободными выбранными портами и уникальным именем контейнера (ниже фактически использованные автором значения, не предложение занять чужие):

1. npm ci --ignore-scripts; npm --prefix server ci --ignore-scripts (оба существующих lockfile).
2. docker run --pull=never --name search-t_7b904be0-pg -e POSTGRES_HOST_AUTH_METHOD=trust -e POSTGRES_DB=search_test -p 127.0.0.1:55461:5432 -d postgres:16
3. docker exec search-t_7b904be0-pg pg_isready
4. DATABASE_URL=postgres://postgres@127.0.0.1:55461/search_test HOST=127.0.0.1 PORT=18961 npm --prefix server run dev
5. curl --fail http://127.0.0.1:18961/health
6. node docs/task-t_7b904be0/live-production.mjs (build с VITE_API_URL=18961, preview 4292; для своих портов адаптировать файл только в QA workspace).
7. Матрицу запускать отдельно по строкам, чтобы не упереться в RPC timeout: MATRIX_WIDTH=390 MATRIX_DPR=2 node docs/task-t_7b904be0/live-matrix.mjs; затем 390/3, 1280/2, 1280/3. JSON сохраняет результаты других строк. Скрипты зависят от реально установленного общего Playwright и /usr/local/bin/google-chrome.
8. node docs/task-t_7b904be0/button-live.mjs; node docs/task-t_7b904be0/two-clients-live.mjs; node docs/task-t_7b904be0/live-network.mjs; python3 docs/task-t_7b904be0/check-live.py.
9. Остановить только свои процессы и docker rm -f search-t_7b904be0-pg; проверить отсутствие своего контейнера.

Неуспешные live-smoke/found-smoke, ранние попытки матрицы и их partial output не доказательства PASS; итоговые данные перечислены выше.

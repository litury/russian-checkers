Ограничения и обязательные ворота:
- Полноценные живые online-фазы с двумя клиентами НЕ подтверждены. Изолированный API prerequisite require.resolve('pg') вернул MODULE_NOT_FOUND. Разрешённая установка касается только root lockfile; серверные зависимости не установлены.
- Независимый QA должен проверить реальные фазы и два клиента; fixture не заменяет эту проверку.
- До QA PASS не публиковать; после PASS — rebase свежего main и повторные проверки, затем release отдельно.
- hotspot: index.html — img поиска и script warmup. boardVerdict.* и ui/result не изменены.

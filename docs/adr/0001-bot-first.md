# ADR 0001. Сначала бот, без WSS

## Контекст

Исходный замысел: живой онлайн с первого релиза (ZIP + WSS, фолбэк hotseat). Для одного игрока в каталоге Яндекса комната на двоих не открывается. Лендинг на Next — второй продукт.

## Решение

Срез 1 — локальная партия человек против бота. Один деплой: Phaser ZIP. Сервера нет. Лендинга нет. Бот — модуль клиента над `src/rules`, не сервис.

`src/rules` остаётся без I/O, чтобы срез с WSS не плодил второй движок.

## Следствия

- Нет протокола, комнат, реконнекта, авторитета сервера.
- Нельзя проверить онлайн, пока не откроем следующий срез.
- Проще довести стол и правила до играбельного ZIP.

## Отклонено

- WSS в первом срезе: второй рантайм, хостинг, протокол, пока стол не доказан.
- Hotseat вместо бота: технически тоньше, в каталоге один человек не с кем сесть.
- Next-лендинг: витрина Яндекса уже есть, стек не Phaser.
- Лестница ботов / сложность: вне среза.

# Соглашения репозитория

Правила структуры для этого репо. Внутренние доки студии сюда не копируем.

## Общее

- Файлы лежат на самом низком уровне, где используются. Корень — только системное: `package.json`, `vite.config.ts`, `tsconfig.json`, `README.md`, `LICENSE`, `.gitignore`.
- Имена из домена шашек: `board`, `bot`, `rules`, не `stuff`, `data1`.
- В папке не больше 7 файлов. Иначе подпапки.
- `README.md` описывает продукт и запуск. Архитектурные решения — `docs/architecture.md` и `docs/adr/`.
- Секреты в git не кладём. `.env*` в `.gitignore`.

## TypeScript

- Файлы и папки: `camelCase`.
- Типы и интерфейсы: `PascalCase`, один тип — один файл (`IMove.ts`).
- Именованные экспорты. `index.ts` только реэкспортирует, логики в нём нет.
- Тесты рядом: `*.spec.ts`.
- Алиас `@/` на `src/`. Без `../../../`.
- Phaser-сцены и объекты — не Vue. `pages/`, `composables/`, `.vue` не заводим.

## Модули

Клиент режется по домену, не по техническим слоям на весь `src/`:

- `app/` — boot
- `modules/board`, `modules/bot` — фичи
- `shared/` — без знания домена
- `config/` — env, флаги

Внутри модуля внутренности в `parts/`. `parts/` не бывает в корне `src/` или корня репо.

`src/rules` — не модуль клиента. Его не тянуть в `client/modules/`.

## Что не копируем из внешних канонов

- Vue-дерево `pages` / `layouts` / `composables`
- C# / `PascalCase` папок / `.csproj`
- UI-библиотека как отдельный пакет в срезе 1

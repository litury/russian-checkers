# Происхождение арта результата

Исторические материалы относятся к спрайтам `client/features/match/result/assets`.
Эти изображения больше не загружаются игрой и не входят в сборку.

- `masters` — оригиналы генерации, а не кэш или снимки тестового браузера.
- `provenance.json` — сводные сведения об инструменте, принятом решении и SHA-256.
- `records` — исторические записи генераций, обработки и согласования.

Актуальный результат использует общий атлас `client/features/menu/assets/menu-controls`
и один диалог для трёх исходов. Происхождение прежних ресурсов сохраняется;
этот каталог описывает историю графики, а не текущий интерфейс.

Упомянутые в записях прежние пути и команды являются историческими и не описывают
текущий способ запуска проекта.

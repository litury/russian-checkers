# Провенанс арта экранов итога (t_1577b2be)

Эта папка хранит происхождение спрайтов `src/client/app/ui/verdict/`: чем сгенерированы,
какими промптами, с какими sha256 и где лежат оригиналы генерации.

## Что опубликовано

Плита заголовка и состояния кнопок (13 файлов WebP, lossless). Полный список с размерами,
DPR и sha256 — в `src/client/app/ui/verdict/manifest.json` и в `provenance.json` этой папки.

## Принятое решение

Дополнительные попытки генерации давали запрещённый брак: красные ядра у поражения и
разъезжавшуюся геометрию пазов между рядами. По решению координатора применён запасной путь —
**одна одобренная владельцем общая плита на все три исхода**, различие исходов несёт текст
заголовка (ПОБЕДА / ПОРАЖЕНИЕ / НИЧЬЯ), а не цвет. Это законно: кодирование дублируется словом.

## Где что лежит

- `provenance.json` — сводная запись по опубликованным плитам (инструмент, решение, нормализация, sha256).
  Рантайм-папка `src/client/app/ui/verdict/` по проверке `verdictSprites.spec.ts` содержит только спрайты и `manifest.json`, поэтому провенанс живёт здесь, а не рядом с артом.
- `records/` — фактические промпты и JSON-записи по каждому вызову генерации: инструмент,
  сессия, путь к сырому ответу, sha256, размеры, режим, крайние значения альфы.
- `masters/` — оригиналы генерации в PNG. Хранятся в репозитории, а не в домашнем каталоге Codex.

## Обработка

Только прямоугольные кадры и lossless WebP. Никаких фильтров, порогов, перекраски кодом,
апскейла или сжатия с потерями. CSS-растяжка (border-image со stretch) и градиенты, изображавшие
металл, удалены; старые `frame-win/loss/draw.webp`, `master.png`, `prompt.txt` из рантайма убраны.

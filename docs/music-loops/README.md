# Музыка меню и боя

Игра использует `menu_music_source.mp3` и `match-b-90s.mp3` из
`client/audio/assets`. Подготовленные петли воспроизводятся целиком,
без runtime-подрезки начала или конца.

`provenance.json` сохраняет происхождение тем, параметры обработки, контрольные
суммы поставки и сопоставление громкости. Это история ресурсов, не инструкция
повторного запуска старых генераторов или браузерных проверок.

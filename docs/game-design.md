# Геймдизайн — срез 1

Источник: геймдизайнер, под модули `rules` / `board` / `bot` / `app`. Приёмка: [issue #2](https://github.com/litury/russian-checkers/issues/2). Код этот файл не заменяет.

Готово = эти пункты можно пройти пальцем на телефоне, без сервера.

## rules

- Доска 8×8, 12 фигур на сторону, ход по тёмным.
- Простая: тихий ход только вперёд по диагонали на 1; бой вперёд и назад.
- Дамка летает и бьёт через поле.
- Взятие обязательно: тихий ход закрыт, если множество взятий непустое.
- Несколько взятий: сторона выбирает любое легальное. Правило максимума в срез 1 не входит.
- Турецкий удар: в одной серии одну фигуру не прыгают дважды, снятие после всей серии. Цепочка = один ход.
- Превращение: простая на дамочном поле становится дамкой. Если серия ещё может продолжаться дамкой — продолжается (русские).
- Нелегальный ход не применяется.
- Победа: у соперника нет фигур или нет легального хода.

## board (`client/modules/board`)

- Пиксель. Клетка и фигура читаются с телефона. Hit-area = клетка.
- Подсветка легальных только у человека, не у бота.
- Первый клик ≤15 с после Game Ready. Без стены правил, без логина.
- Sticky не перекрывает доску.

## bot (`client/modules/bot`)

- `rules` считает легальные → если есть взятия, только они → равновероятно один ход (цепочка целиком) → тот же `apply`.
- Нет поиска, оценки, уровней, текста «ИИ».
- Ход бота виден на столе.

## цикл партии (`client/app`)

- Человек ходит → бот отвечает → пока нет конца.
- Конец: экран результата → ещё раз.
- Game Ready один раз на старте.
- Interstitial только после первой законченной партии, не до первого хода. На рекламе пауза звука и хода.

## Вне среза

WSS, комната, реконнект, hotseat, лендинг, Next, лестница ботов, сложность, рейтинг, скины, чат, туториал, бить максимум.

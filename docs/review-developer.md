# Ревью разработчика — russian-checkers, срез 1

Срез: локальная партия человек vs бот. Без мультиплеера.
Область: движок правил, бот, архитектура, типы, тесты, Vite/Biome, Yandex SDK, читы/нелегальные ходы, баги состояния. Визуал/бренд не разбирались.

Прогон (этот clone): `npm test` — 10 файлов / 54 теста, все зелёные. `./node_modules/.bin/tsc --noEmit` — 0. `biome check .` — 2 замечания (импорты в `gameScene.ts`, формат `layout.spec.ts`).

## Что сделано крепко

Чистый `src/rules` без DOM/Phaser/SDK. Это совпадает с `docs/architecture.md` и ADR 0001: один движок, позже можно импортировать с сервера.

Контракт хода узкий и достаточный: `IMove = { from, path }`. Генерация и `apply` живут на нём одном.

Обязательное взятие в одном месте — `legalMoves.ts`: если `collectCaptureMoves` непустой, тихие ходы не отдаются.

Реализации правил среза в генераторе выглядят верными:

- простая бьёт назад (`manCaptureOptions` по всем `DIAGONALS`);
- дамка летает (`kingCaptureOptions` / тихий луч в `findQuietMoves.ts`);
- турецкий удар: жертвы в поиске не снимаются, `captured: Set`, повторный прыжок и пролёт через уже сбитую клетку закрыты;
- превращение в середине серии: и поиск, и `apply.ts` меняют `kind` на `king` на дамочном ряду и продолжают.

`apply` — единственная точка мутации позиции: клон, сверка `moveKey` с `legalMoves`, иначе `null`. Исходная позиция не портится. Это правильный античит для локального стола (консоль всё ещё может крутить память, серверного авторитета в срезе нет — так и задумано).

Бот тонкий и честный: `pickBotMove` = `pickUniform(legalMoves)`. Взятие обязательно, потому что его отдаёт rules. `random() === 1` не вылезает за массив (`pickUniform.ts`).

Цикл партии в `gameScene.ts` режет фазы `title | human | bot | over`. Ход человека и бота только из `legalMoves`. Чужой клик / своя без хода / пустая не применяются. Своя без легального хода при бое — `deny`, позиция та же.

Yandex-обвязка в целом по доке платформы:

- `/sdk.js` в `index.html` — канонический путь Яндекса;
- нет скрипта → stub, Game Ready no-op, реклама не зовётся (как в README);
- `LoadingAPI.ready()` в конце `create()` после стола;
- `game_api_pause` / `game_api_resume` с догоняющим `onPause`, если пауза пришла до подписки;
- interstitial через `showFullscreenAdv` только из `endMatch`, не до первого хода.

Стек среза собран: Phaser 4, Vite 8, TS strict (`noUnusedLocals`, `verbatimModuleSyntax`, alias `@/`), Vitest на `src/**/*.spec.ts`, Biome recommended. Тесты лежат рядом с кодом.

## Баги и риски

### P0

Нет. Однострочного краша не нашёл, код не менял.

### P1

1. Выбор хода в UI не равен `IMove`.
   `gameScene.ts` `onSquare`: `moves.find` по `from` + **последней** клетке `path`. Две разные серии с одним финишем — игрок не выбирает серию, берётся первая в порядке обхода доски/`DIAGONALS`. GDD: «сторона выбирает любое легальное».
   Там же: `uniqueHopLands` / лучи в `createBoardView.ts` рисуют промежуточные клетки цепочки, а клик по промежуточной не матчится и **сбрасывает** `selected`. Серия из `rules.spec` (`path: [(4,4), (2,6)]`) с точки зрения ввода ломается, если ткнуть яму на (4,4).
   Читы тут ни при чём: `apply` честный, ломается контракт «клетка → конкретный IMove».

2. Нет `GameplayAPI.start` / `stop`.
   `yandexSdk.ts` / `IYandexSdk.ts` знают только LoadingAPI, fullscreen adv, pause/resume. Модерация Яндекса (маркер геймплея 1.19.3): старт партии, меню/титул, конец, реклама. События паузы с `GameplayAPI` связаны; без разметки каталог и отладка платформы будут красными, даже если стол играет.

3. Реклама не ставит паузу сама.
   `endMatch` зовёт `showFullscreenAdv` без `setPaused`. Ставка на `game_api_pause`. Если событие не пришло (или пришло после `onOpen`), тикают таймер, звук и `botTimer`. GDD: «на рекламе пауза звука и хода». `onOpen` в хендлерах сцены не используется.

4. Спеки rules тонкие относительно движка.
   `rules.spec.ts` — 12 тестов. Нет: тихий ход простой только вперёд; тихий дамки на N; две смежные на диагонали (не пролететь обе); ветка серии без правила максимума; коллизия двух `path` с одним финишем; цикл турецкого удара с двумя жертвами; тихое превращение. Тест «turkish strike» с одной жертвой почти ничего не ловит. Регрессия правил пройдёт зелёным.

### P2

- `createBoardView.ts` `reset` не сбрасывает внутренний `moving`. Сейчас «ещё раз» только после анимации, путь закрыт. `tweens.killAll()` в `startMatch` / `showTitle` + ранний `return` в `playMove` без `onDone` — потенциальный вечный `this.moving` у сцены.
- `apply` после анимации. Если `apply` вернул `null` (рассинхрон view/позиции), `playHuman` просто `return` без `refresh` — спрайты уже уехали.
- Сдача (`resignMatch`) не идёт в `endMatch`: нет interstitial, нет общего конца партии. Человек всегда белые, resign = победа чёрных — ок, но монетизация/SDK-цикл рвутся.
- Ничьей нет (`winner.ts` только сторона или `null`). Для GDD среза ок; две дамки крутятся бесконечно.
- Нет `GameplayAPI` и нет `off` у слушателей SDK (одна сцена на жизнь игры — терпимо).
- Дубль `sameSquare`: `src/rules/parts/board.ts` и `src/client/shared/sameSquare.ts`.
- Дубль `src/vite-env.d.ts` (модули png/ogg) и `src/viteEnv.d.ts` (`vite/client`).
- `tsconfig.json` `"types": []` — сознательно пустой; держится на `viteEnv.d.ts` и прямых импортах vitest.
- `gameScene.ts` ~665 строк, из них пачка preload-URL; `createBoardView.ts` ~1876 строк и сам себе state-машина. `src/client/app/` больше 7 файлов (`docs/conventions.md`).
- Biome не чистый (2 ошибки). `npm test` / tsc зелёные, `npm run check` — нет.
- Vite `alias` через `URL.pathname` (Windows-хрупко; для ZIP в Яндекс не блокер).

Читы: из UI нелегальный ход не применяется. Подмена `IMove` в рантайме упрётся в `apply` → `null`. Для среза 1 этого достаточно. Не логируйте легальные ходы как «достаточно» — UI должен выбирать **конкретный** path.

## 5 следующих инженерных шагов

1. Свести клик к одному `IMove`: либо пошаговый выбор клетки `path[i]`, либо клик только по терминальным клеткам и явный выбор при коллизии финишей. Не рисовать промежуточную яму, если она не является легальным завершением. Покрыть спеком позицию из `rules.spec` с `path.length > 1` и двумя path с общим концом.

2. Дописать `rules.spec.ts` до таблицы правил среза (тихие, летун, блок, турецкий цикл из двух жертв, превращение тихое и в серии, короткая терминальная серия легальна). Пока этого нет, любой рефактор `findCaptures.ts` — лотерея.

3. Расширить `IYandexSdk`: `GameplayAPI.start/stop` на `startMatch` / `showTitle` / `endMatch` / pause. В `showFullscreenAdv` пауза на `onOpen`, снятие на `onClose`/`onError`, плюс уже существующие `game_api_*`.

4. Цикл партии вынести из `GameScene` (preload vs match machine). В `board.reset` обязательно `moving = false`; `apply` до или атомарно с завершением анимации; при `apply === null` — `sync` с текущей позицией, не мёртвый return.

5. Один проход по гигиене репо: починить Biome, слить `sameSquare` и `vite-env`/`viteEnv`, решить resign → тот же `endMatch` (реклама + overlay). Не трогать визуал.

Согласованность с GDD среза по самому движку высокая. Играбельный ZIP упирается не в генератор ходов, а в контракт ввода, разметку Яндекса и дыры в тестах rules.

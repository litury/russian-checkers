# Задача: табличка имени в газоне (без коммита)

Делай сразу. Не пиши @hermes через `message_agent` — чат занят (`target_busy`). Результат только файлами. Кадры покажи человеку **до** записи поверх игровых PNG.

Код не трогать. Это арт. Встройку в Phaser потом делает @developer.

## Зачем

Сейчас «Ты» / «Бот» — Tiny5 над шеллом часов. Дальше это **ники онлайн**. Имя не печь в спрайт.

Референс по ощущению: охотничьи дощечки Ведьмака — дерево, гвозди, втыкается в траву. Не городская доска объявлений и не замена часов.

## Спека спрайта

Один ассет, два инстанса (своё / чужое). Правую сторону зеркалит код.

| | |
|---|---|
| Файл | `src/client/app/ui/hud/hud_name_plank.png` (каталог создай, если нет) |
| Холст | 128×128 RGBA, прозрачный фон, без #FF00FF |
| Содержимое | кол + горизонтальная плашка. Плашка — «окно» под текст: дерево, без букв |
| Полезный силуэт | плашка ~96×36, кол вниз, касание травы внизу кадра |
| Стиль | то же дерево, что меню/HUD (меню `hud_menu_f*`, луг). Пиксель, не живопись |
| Состояния | один скин. Hot/idle у часов, не у таблички |

Не рисовать: «Ты», «Бот», цифры, часы, фигурки.

Текст поверх (Phaser, не ты):

- шрифт **Tiny5 15px** (сетка 5; минимум 14)
- цвет как HUD-текст
- max **12** символов кириллицы, иначе `…`
- якорь: центр плашки

## Не делать

- не трогать шеллы часов
- не заводить второй шрифт (Russo One — только вордмарк)
- не коммитить, не пушить
- платные PixelLab-генерации — апрув человека

PixelLab: `PIXELAB_API_TOKEN` в `.env` профиля illustrator, скилл `pixellab-sprites`. Gemini = мудборд.

# Цифры в колодце крупнее + старт оба красные

Код `@developer`. Новый арт не нужен. Коммит/пуш только по команде человека.

## 1. Цифры таймера

Сейчас Tiny5 **15px**, origin 0.5, точка `hudClockEWell*` — цифры сидят у **низа** чёрного экрана, сверху пусто.

Нужно: увеличить, чтобы по **высоте** заполнили чёрный колодец. **За пиксель безеля не выходить** (ни верх, ни низ, ни бока). Ширина «60» и «0» тоже внутри.

Tiny5 только кратно 5. Сначала **20px**. Если 20 не влезает — подобрать якорь (origin 0.5/1 на пол колодца, чуть поднять well Y), не прыгать на 25 вслепую. Имена (`nameFontPx = 15`) не трогать.

Цифры по-прежнему Tiny5 оверлеем, не печь в PNG.

## 2. Старт — оба красные

`paintClock` при `countingIn` (и `phase === 'over'`) шлёт `turn: null` → оба **idle серые**, «пустые без цвета». Человек: на старте оба **красные**, цифры видны.

`turn == null` → оба `hot` кадр 0 (красный тускло), не idle. После 3-2-1 обычная смена хода (зелёный держит кадр 2 / красный кадр 0).

Idle-PNG можно оставить в бандле, на матчевом HUD до первого хода не показывать.

Новые спрайты. Вечную петлю ламп. Таблички имён. Коммит без команды.
